# ぱっと かず（MieeL）

かずを 1つずつ かぞえずに「ぱっと みて わかる」ちから（サビタイジング）を、1〜3 → 5 → 10 の じゅんに そだてる さんすうの アプリです（特別支援教育向け・iPad / iPhone）。

## ステージ（19）
- 🌱 **1・2・3 の しま**：いち と に／さん まで／ばらばらでも 3／おなじ かずは どれ／あわせて 3
- 🖐️ **5 の しま**：よん と ご／5まで いろいろ／5の わく／わく なしでも／どっちが おおい？／あわせて 5／かくれんぼ 5（5 は 3 と 2）／あと いくつで 5？
- 🏰 **10 の しま**：5と いくつ（10 の わく）／6〜10 わく なし／あわせて 10まで／あと いくつで 10？／かくれんぼ 10／チャンピオン

## くふう
- **ぱっと みせて かくす**（カーテン）。みせる じかんは じどうで ちょうせい（3もん つづけて せいかい → はやく、まちがい → ゆっくり）
- **いろいろな もの・ならべかた**：くろい いし・いろの まる・ブロック・りんご・くるま など 11しゅるい × さいころ・ならび・2れつ・ばらばら・かたまり・わく あり／なし
- **あわせて・かくれんぼ・あと いくつ** で「1 と 2 で 3」「5 は 3 と 2」を みて おぼえる
- **まちがえても ばつ なし**：その ばで ゆっくり かぞえて みせ、ただしい こたえで おわる
- ゲーム：すすむ キャラ、ほし 3つ、シールちょう（30まい）、じゆうに あそぶ
- 先生用（⚙️ 1.5秒 ながおし）：子どもごと、こたえの ボタン（すうじ／すうじ＋まる／え だけ）、こたえの かず、もんだい数、つかう もの、きろく（かず × あそび の せいかいりつ表・CSV）、A4 プリント 6しゅるい（こたえ つき）
- 「やすみの しゅくだい メーカー」から プリントを とりこめます（MieelPrintAPI）
